    CAPÍTULO 12 DE 12

    Exportación y flujo de trabajo profesional

    Experto 50 min

    El camino a experto: formatos correctos, perfiles de color, organización y portfolio.

    Lo que vas a aprender

    • Elegir el formato de exportación correcto para cada destino.
    • Preparar archivos para impresión con perfiles de color adecuados.
    • Optimizar imágenes para web sin perder calidad perceptible.
    • Organizar un flujo de trabajo profesional y construir tu portafolio.

    01Formatos y cuándo usar cada uno

    Elegir el formato equivocado es uno de los errores más comunes incluso en usuarios avanzados:

    • .PSD: archivo de trabajo, con capas intactas — nunca lo entregues como archivo final.
    • .JPG: fotografías para web, con compresión con pérdida — ideal para redes sociales y correo.
    • .PNG: gráficos con transparencia o bordes duros (logotipos, iconos, UI).
    • .TIFF: impresión profesional, sin pérdida de calidad, admite capas y perfiles ICC.
    • .PDF: documentos e imprenta, con estándares como PDF/X para artes finales.

    02Exportar para web (Guardar para Web / Exportar como)

    Archivo > Exportar > Exportar como permite comparar calidad vs. peso del archivo en tiempo real, redimensionar y elegir el perfil de color "sRGB" (estándar universal para navegadores).

    03Preparar para impresión

    Convierte a modo CMYK solo al final (Imagen > Modo > Color CMYK), incrusta el perfil ICC correspondiente a la imprenta que uses, y verifica el Overprint Preview para anticipar cambios de color. Deja al menos 300 ppp de resolución real.

    04Organización y flujo de trabajo experto

    Un flujo profesional consistente marca la diferencia entre un aficionado y un experto:

    • Nombra capas y grupos de forma descriptiva desde el principio, no al final.
    • Usa una convención de nombres de archivo con versión (proyecto_v01.psd, v02...).
    • Guarda una plantilla (.psdt) para proyectos recurrentes (posts de redes, portadas).
    • Haz respaldo en la nube y localmente; los .psd de proyectos grandes pueden pesar varios GB.

    05Construir tu portafolio

    Selecciona tus 10-15 mejores piezas, muestra procesos (antes/después) cuando aporte valor, y manténlo actualizado. Una consistencia visual y un criterio de edición propio es lo que distingue a un editor experto de uno intermedio.

    Entrega siempre lo justo

    Entrega solo el formato y tamaño que tu cliente o plataforma necesita; adjuntar un PSD de 2 GB para un post de Instagram genera más problemas que soluciones.

    Ejercicio final: paquete de entrega

    1. Toma cualquier proyecto de los capítulos anteriores.
    2. Expórtalo en JPG optimizado para web (máx. 500 KB) y en TIFF a 300 ppp para impresión.
    3. Guarda una plantilla .psdt reutilizable a partir de su estructura de capas.
    4. Documenta el proyecto con una imagen de antes/después para tu portafolio.
