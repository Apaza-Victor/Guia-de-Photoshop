    CAPÍTULO 11 DE 12

    Automatización y productividad

    Avanzado 45 min

    Acciones, procesamiento por lotes, scripts e IA generativa para trabajar más rápido.

    Lo que vas a aprender

    • Grabar y ejecutar Acciones para tareas repetitivas.
    • Procesar por lotes decenas de imágenes a la vez.
    • Entender qué puede automatizarse con Scripts.
    • Incorporar IA generativa (Relleno y Ampliación generativa) al flujo de trabajo.

    01Acciones (Actions)

    El panel Acciones (Ventana > Acciones) graba una secuencia de pasos para reproducirla después con un clic. Ideal para procesos repetitivos: redimensionar, aplicar una marca de agua, exportar en un formato concreto.

    • Pulsa el botón grabar (círculo rojo), realiza los pasos deseados y detén la grabación.
    • Puedes insertar "paradas" para introducir texto manual (por ejemplo, cambiar el nombre de archivo).
    • Las acciones se guardan como .atn y se pueden compartir entre equipos.

    02Procesamiento por lotes (Batch)

    Archivo > Automatizar > Procesar por lotes aplica una Acción grabada a todos los archivos de una carpeta automáticamente: perfecto para redimensionar cientos de fotos de un evento en minutos.

    03Scripts

    Photoshop admite scripts en JavaScript (Archivo > Scripts) para automatizaciones que las Acciones no cubren, como generar variaciones de un diseño a partir de una hoja de datos (Archivo > Scripts > Cargar archivos en pila, entre otros) o exportar capas como archivos independientes.

    04IA generativa en el flujo profesional

    El Relleno generativo permite escribir un prompt de texto para generar contenido dentro de una selección (por ejemplo, extender un fondo). La Ampliación generativa extiende el lienzo con contenido coherente al recortar en un formato distinto. Trátalas como un punto de partida: siempre revisa y ajusta el resultado manualmente.

    Automatiza solo lo repetitivo

    Si haces el mismo proceso más de tres veces en un proyecto, probablemente valga la pena grabarlo como Acción: el tiempo invertido se recupera rápido.

    Guarda copias antes de un lote

    Al procesar por lotes sobre las carpetas originales, un error en la Acción puede sobrescribir archivos. Trabaja siempre sobre copias.

    Ejercicio: exportación en lote

    1. Graba una Acción que redimensione una imagen a 1080 px de ancho y la exporte como JPG calidad 80.
    2. Coloca 5-10 imágenes de práctica en una carpeta.
    3. Ejecuta "Procesar por lotes" aplicando la Acción a toda la carpeta.
    4. Verifica que todas las imágenes de salida tengan el tamaño y formato correctos.
